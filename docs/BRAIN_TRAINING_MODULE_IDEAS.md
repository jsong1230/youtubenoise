# 시니어용 두뇌훈련 모듈 아이디어

## 현재 구현된 모듈 (5개)
1. **number_memory** - 숫자 기억
2. **pattern_sequence** - 패턴 순서
3. **word_association** - 단어 연상
4. **clock_reading** - 시계 읽기
5. **korean_word_puzzle** - 한글 퍼즐

## 추가 모듈 아이디어 (우선순위 순)

### 1. 🎨 color_memory (색상 기억) ⭐ 추천
**설명**: 화면에 나타나는 색상 조합을 기억하는 훈련
- **난이도**: 쉬움
- **구현 난이도**: 쉬움 (PIL로 색상 박스 생성)
- **시니어 친화성**: 높음 (시각적, 직관적)
- **예시**: 
  - 3-4개의 색상 박스를 순서대로 보여주고, 나중에 같은 순서를 맞추기
  - 또는 색상 이름을 보고 색상 박스 선택하기
- **GPT 필요**: 색상 조합 생성
- **이미지 필요**: 없음 (PIL로 생성 가능)

### 2. 🔢 simple_calculation (간단한 계산) ⭐ 추천
**설명**: 덧셈/뺄셈 같은 간단한 계산 문제
- **난이도**: 쉬움~보통
- **구현 난이도**: 쉬움 (숫자만 생성)
- **시니어 친화성**: 높음 (일상적, 친숙함)
- **예시**: 
  - "15 + 23 = ?" 같은 덧셈/뺄셈
  - 10의 배수, 5의 배수 등 쉬운 숫자로 구성
- **GPT 필요**: 문제 생성 (선택사항, 직접 생성도 가능)
- **이미지 필요**: 없음

### 3. 📍 direction_memory (방향 기억) ⭐ 추천
**설명**: 화살표 방향을 기억하는 훈련
- **난이도**: 쉬움~보통
- **구현 난이도**: 쉬움 (PIL로 화살표 그리기)
- **시니어 친화성**: 높음 (시각적, 직관적)
- **예시**: 
  - 3-4개의 화살표(↑↓←→)를 순서대로 보여주고 기억하기
  - 또는 화살표 방향을 보고 "위", "아래" 등으로 답하기
- **GPT 필요**: 없음 (직접 생성 가능)
- **이미지 필요**: 없음 (PIL로 생성)

### 4. 🐾 category_classification (카테고리 분류) ⭐ 추천
**설명**: 여러 단어 중 같은 카테고리에 속하는 것을 찾기
- **난이도**: 보통
- **구현 난이도**: 보통 (GPT로 단어 생성)
- **시니어 친화성**: 높음 (일상 단어 사용)
- **예시**: 
  - "사과, 바나나, 자동차, 오렌지" 중 과일이 아닌 것 찾기
  - "강아지, 고양이, 새, 자동차" 중 동물이 아닌 것 찾기
- **GPT 필요**: 단어 리스트 생성
- **이미지 필요**: 없음

### 5. 🔤 word_order (단어 순서 맞추기)
**설명**: 문장의 단어 순서를 맞추는 훈련
- **난이도**: 보통
- **구현 난이도**: 보통 (GPT로 문장 생성)
- **시니어 친화성**: 중간 (문법 이해 필요)
- **예시**: 
  - "나는 / 학교에 / 갑니다" → 올바른 순서 맞추기
  - "아침에 / 커피를 / 마셨습니다" → 순서 맞추기
- **GPT 필요**: 문장 생성 및 단어 분리
- **이미지 필요**: 없음

### 6. 🎯 shape_matching (도형 매칭)
**설명**: 도형의 모양, 색상, 크기를 매칭하는 훈련
- **난이도**: 쉬움
- **구현 난이도**: 쉬움 (PIL로 도형 그리기)
- **시니어 친화성**: 높음 (시각적)
- **예시**: 
  - "빨간 원"과 같은 도형 찾기
  - 여러 도형 중 같은 모양 찾기
- **GPT 필요**: 없음 (직접 생성 가능)
- **이미지 필요**: 없음 (PIL로 생성)

### 7. 📅 date_memory (날짜 기억)
**설명**: 날짜나 요일을 기억하는 훈련
- **난이도**: 쉬움~보통
- **구현 난이도**: 쉬움
- **시니어 친화성**: 높음 (일상적)
- **예시**: 
  - "오늘은 11월 23일입니다. 3일 후는?" 
  - "월요일 다음 요일은?"
- **GPT 필요**: 문제 생성 (선택사항)
- **이미지 필요**: 없음

### 8. 🎵 rhythm_pattern (리듬 패턴)
**설명**: 간단한 리듬 패턴을 기억하는 훈련 (시각적 표현)
- **난이도**: 보통
- **구현 난이도**: 중간 (시각적 리듬 표현)
- **시니어 친화성**: 중간
- **예시**: 
  - "짧음-짧음-길음" 패턴을 시각적으로 보여주고 기억하기
  - 박자 패턴 맞추기
- **GPT 필요**: 없음
- **이미지 필요**: 없음 (PIL로 생성)

### 9. 🧩 simple_logic (간단한 논리)
**설명**: 간단한 논리 문제
- **난이도**: 보통~어려움
- **구현 난이도**: 중간 (GPT 필요)
- **시니어 친화성**: 중간 (추상적 사고 필요)
- **예시**: 
  - "A는 B보다 크다. B는 C보다 크다. 가장 큰 것은?"
  - "모든 새는 날 수 있다. 펭귄은 새다. 펭귄은 날 수 있는가?" (X)
- **GPT 필요**: 문제 생성
- **이미지 필요**: 없음

### 10. 🔍 find_difference_text (텍스트 차이 찾기)
**설명**: 두 문장에서 다른 부분 찾기
- **난이도**: 쉬움~보통
- **구현 난이도**: 쉬움 (텍스트 비교)
- **시니어 친화성**: 높음 (읽기 능력)
- **예시**: 
  - "나는 학교에 갑니다" vs "나는 학교에 갔습니다" → 다른 부분 찾기
  - "고양이가 잠을 잡니다" vs "고양이가 잠을 잡니다" → 오타 찾기
- **GPT 필요**: 문장 쌍 생성
- **이미지 필요**: 없음

## 추천 우선순위 (구현 용이성 + 시니어 친화성)

### 1순위 (즉시 구현 추천)
1. **color_memory** - 색상 기억 (구현 쉬움, 시니어 친화적)
2. **simple_calculation** - 간단한 계산 (구현 쉬움, 친숙함)
3. **direction_memory** - 방향 기억 (구현 쉬움, 시각적)

### 2순위 (다음 단계)
4. **category_classification** - 카테고리 분류 (GPT 활용)
5. **shape_matching** - 도형 매칭 (PIL 활용)

### 3순위 (향후 고려)
6. **word_order** - 단어 순서 맞추기
7. **date_memory** - 날짜 기억
8. **find_difference_text** - 텍스트 차이 찾기

## 구현 시 고려사항

1. **시니어 친화성**
   - 큰 글자, 높은 대비
   - 명확한 지시사항
   - 충분한 시간 제공

2. **구현 난이도**
   - PIL로 생성 가능한 것 우선 (이미지 다운로드 불필요)
   - GPT API 의존도 최소화
   - 복잡한 로직 피하기

3. **다양성**
   - 각 모듈마다 다양한 문제 생성 가능해야 함
   - `problem_index` 활용하여 반복 방지

4. **다국어 지원**
   - 한글/영어 모두 지원 가능하도록 설계
   - 텍스트 기반 모듈은 GPT로 다국어 생성
