# Public Domain Music Library

이 디렉토리는 Public Domain 또는 CC0 음악 파일을 저장하는 위치입니다.

- 하위 폴더(예: `jazz/`, `classical/`, `christmas/`)를 자유롭게 만들어 MP3/WAV 파일을 넣어주세요.
- 모든 MP3/WAV 파일은 Git에 커밋되지 않도록 `.gitignore`에 등록되어 있습니다.
- 새로 다운로드한 음악을 추가한 뒤에는 `scripts/public_domain_catalog.py --refresh --summary`를 실행해 카탈로그를 갱신하세요.

> ⚠️ 중요: 이 디렉토리에는 용량이 큰 파일이 들어가기 때문에 Git에 커밋하지 마세요.
